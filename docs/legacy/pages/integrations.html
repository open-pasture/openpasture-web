A grazing plan is only as good as its picture of the ground. The kit is built to be adaptive to whatever data a farm actually has: more sources sharpen the plan, and missing sources degrade it rather than break it. A farm with nothing but the farmer's own field notes still gets a brief.

Design principle

Degrade, do not break

Most agricultural software assumes a sensor budget the average farm does not have, then fails closed when the data is missing. We build the other way around. The farm model treats every source as optional evidence. Satellite sharpens a recovery estimate that field notes already made; a drone pass sharpens it further. Take all of it away and the planner still runs on what the farmer typed in last week — it just asks more questions before committing to a move.

That is also why NEEDS_INFO is a first-class answer alongside MOVE and STAY. A system that guesses when it is short on evidence is worse than one that says so.
