What you get

Everything that is annoying to run

Accounts and farm organizations Authentication and hosted farm organizations, so a farm can have more than one person in it without sharing a login.
Tenant API keys Issue and revoke keys per farm. The key scopes every tool call to your farm's data and nothing else.
Hosted MCP endpoint A managed MCP runtime you point ChatGPT or any MCP client at. No per-farm services to deploy, patch, or keep alive.
Synced farm data Paddocks, herds, observations, and plans kept in sync and readable from the portal, so you can see the state the agent is reasoning over.

Getting connected

Three steps

STEP 01

Create your farm

Sign up and describe the farm once: name, timezone, paddocks, and herd groups. Onboarding walks the setup and writes the initial farm state.

STEP 02

Generate an API key

The portal issues a tenant key. It authenticates your requests against the shared hosted runtime and scopes them to your farm.

STEP 03

Connect your assistant

Paste the MCP URL into ChatGPT, Claude, Cursor, or any MCP-capable client. From then on you ask it about the farm in plain language, and it answers against real farm state.

Honest limits

What the cloud does not do yet

It does not move your animals. It does not drive a collar. The daily loop ships as a recommendation — move, stay, or ask a question first — and the farmer executes it. The satellite pipeline is a prototype and is not yet part of the production planning loop. Hardware does not exist; there is nothing to buy.

Access for new accounts is gated while the beta is small. If you sign up and do not get in immediately, that is why.

Or run it yourself

A farm that self-hosts everything pays us nothing and loses nothing. That is deliberate, and it is not going to change.
