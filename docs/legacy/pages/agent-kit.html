Agent Kit

The open-source core

The farmer brings a conversation surface. The agent brings reasoning. The kit brings the farming domain: executable tools, portable skills, curated grazing knowledge, and a local-first model of the farm. It bolts onto an agent you already use and turns it into a grazing advisor.

Runtime modes

Three ways to run it

The kit is framework-neutral. The richest runtime is a coding agent with CLI access and code execution, but the same tools and skills reach any MCP-capable client.

01 Coding agent A coding agent reads the skills, runs the openpasture CLI, inspects farm state on disk, and composes workflows directly in a workspace.
02 MCP client ChatGPT, Claude, Cursor, and other MCP-capable clients reach the same tools and skills through the MCP connector.
03 Hermes adapter The original Hermes plugin entry point is preserved as a supported adapter.

Quickstart

Running in about five minutes

SQLite by default, so there is nothing to provision. Point it at Convex later if you want hosted sync.

install
pip install -e .

export OPENPASTURE_STORE=sqlite
export OPENPASTURE_DATA_DIR="$HOME/.openpasture"
export OPENPASTURE_BRIEF_TIME="06:00"
set up a farm and ask for the morning brief
openpasture tools list
openpasture tool run setup_initial_farm --json '{
  "name": "Willow Creek",
  "timezone": "America/Chicago",
  "herd": { "id": "herd_1", "species": "sheep", "count": 120 },
  "paddocks": [{ "id": "paddock_home", "name": "Home", "status": "grazing" }]
}'
openpasture tool run generate_morning_brief --json '{}'

The brief comes back as MOVE, STAY, or NEEDS_INFO, with the reasoning attached. Full setup, including the Convex backend and the MCP connector, is in the docs.

What is inside

The pieces

Domain and storage Farms, paddocks, herds, observations, and plans as first-class objects. SQLite-backed and local-first by default, with an optional Convex backend for hosted or self-hosted sync.
Tools Dict-in, JSON-out handlers for farm setup, observations, planning, knowledge, and data pipelines. Framework-neutral, so the same catalog serves every connector.
Skills Portable markdown runbooks that teach an agent how to work through farm operations rather than guess at them.
Knowledge Curated practitioner knowledge from trusted regenerative agriculture sources, with seed loading, embeddings, retrieval, and ingestion batches.
Ingestion Pipelines for external farm signals — weather, satellite, photos, and vendor telemetry — set up, persisted, and executed on a schedule.
Briefing Farm context assembly, the default advisor, and recurring local scheduling that puts a brief in front of the farmer each morning.

Self-host it or let us run it
