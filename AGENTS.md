# AGENTS.md

This repository is the closed OpenPasture marketing site.

Before changing product copy, read the canonical public guidance in
`../openpasture-agent-kit/AGENTS.md`, `../openpasture-agent-kit/SOUL.md`, and
`../openpasture-agent-kit/docs/voice-and-boundaries.md`.

## Repo Role

`openpasture-web` owns public positioning, pricing, lead capture, and marketing
pages. It should point readers toward the hosted cloud product and public docs
without becoming the source of truth for product behavior.

## Copy Rules

- Use plain farmer-to-farmer language.
- Explain the split between the public agent kit, hosted cloud product, and
  marketing site when needed.
- Do not overclaim autonomy. OpenPasture can help observe, organize, recommend,
  and explain. The farmer remains the operator.
- Do not claim the product controls livestock, gates, hardware, or farm
  decisions unless that capability is real and explicitly approved.
- Keep licensing language out of marketing copy unless it matches the source
  license files.
